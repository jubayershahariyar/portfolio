# Jubayer Shahariyar – Portfolio

My personal portfolio website, built from scratch with HTML, CSS and JavaScript.

**Live site:** https://jubayershahariyar.github.io/portfolio/

## About
I'm an aspiring frontend developer learning to build clean, responsive and user-friendly websites. This portfolio is one of my learning projects.

## Features
- Responsive layout for mobile, tablet and desktop
- Light, dark and system theme with a toggle
- Mobile navigation menu
- Sections: Home, About, Projects, Experience, Contact
- One-click email copy button

## Built with
- HTML5
- CSS3 (cascade layers, custom properties, `light-dark()`)
- JavaScript (vanilla, no frameworks)

## Run locally
```bash
git clone https://github.com/jubayershahariyar/portfolio.git
```
Then open `index.html` in your browser.
